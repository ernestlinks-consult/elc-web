# Chip

Chips show a short set of choices as pills: radio chips for one answer, checkbox chips (`multiple`) for several.

- Use for 2–7 short options (package, level, countries, filters). Longer lists use a select.
- Selected chips fill `blue` with white text; unselected have a `line-strong` border.
- Wrap chips in a `fieldset` with a `legend` naming the question; give radio chips the same `name`.
- Filter tabs on list pages (Blog topics, Scholarship status, Video platform) use the same look as buttons with `aria-pressed`.
