# Badge

A badge is one or two words of status or category; its colour supports the word and never replaces it.

| Tone | Words it carries |
| --- | --- |
| `red` | LIVE, FASTEST, FREE · LIVE (white on `red`) |
| `new` | New lead, overdue time (`red-text` on `red-tint`) |
| `success` | Open, Paid, Shown |
| `warning` | Opening soon, In review, Started, Sample data |
| `neutral` | Closed, Hidden, Draft |
| `blue` / `solid` | Categories (Bridging, Master's) and emphasis |

Uppercase, 12px, 800 weight. Keep to three words or fewer.
