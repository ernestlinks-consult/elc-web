# Field

A field is a visible label above an input, with optional help text and a plain-language error; never use the placeholder as the label.

- Mark required fields with a red-text star and optional ones with "(optional)". In Start online, most fields after step 1 are optional.
- Help text explains why we ask ("We message you here").
- Errors say what to do ("Enter a full email address, like ama@gmail.com."), sit under the field, are announced to screen readers, and give the input a 2px `red-text` border.
- Ghana phone numbers accept `0XX XXX XXXX` or `+233`; never reject spaces.
- Borders are `line-strong` (3:1). Never ask for Ghana Card, SSNIT or Voter ID numbers on the website.
- `multiline` renders a textarea.
