# Logos

Official ErnestLinks Consult logos, converted from the PDF masters with the Conthrax wordmark kept as shapes.

- `elc-logo-stack.svg` — emblem + three-line wordmark, blue and black. Default on white.
- `elc-logo-stack-white.svg` — the same in white for blue and blue-deep backgrounds.
- `elc-logo-wide.svg` — "ERNESTLINKS / CONSULT" two-line version for wide spaces.
- `elc-mark.svg` — emblem with the red star, no words. Favicons, avatars, embeds.
- `elc-star.svg` — the red star alone (#EA0606). Accent only; never on blue.
